# 📰 BlogNewsPortal Frontend

A modern and responsive Blog & News Portal built with React and Vite.

---

## 🚀 Features

- Modern Responsive UI
- JWT Authentication
- User Registration & Login
- Home Page
- Articles Listing
- Article Details
- Category Filtering
- Search Articles
- Pagination
- Like Articles
- Comment System
- Author Dashboard
- Admin Dashboard
- Privacy Policy
- Terms & Conditions
- Disclaimer
- Contact Page

---

## 🛠 Technologies

- React 19
- Vite
- Bootstrap 5
- Axios
- React Router DOM
- JavaScript (ES6)
